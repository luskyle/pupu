# pupu v0.3.1

## 下载什么

- **Chrome / Edge 扩展**：`pupu-v0.3.1.zip`，解压后在 Chromium 浏览器中加载。
- **Firefox 桌面版 140+ 扩展**：`pupu-firefox-v0.3.1.zip`。在 `about:debugging#/runtime/this-firefox` 选择「临时载入附加组件」，然后选择 ZIP 或解压后的 `manifest.json`。
- **Linux x64 桌面实验版**：`pupu-desktop-v0.3.1-linux-x64.tar.gz`，解压完整目录后运行 `pupu-linux-x64/pupu`。
- `SHA256SUMS`：上述三个归档的 SHA-256 校验值。

Firefox ZIP **未经 Mozilla 签名**，普通 Firefox 重启后会移除临时安装的扩展；持久安装需要 Mozilla 签名后的附加组件。此 Release 不会自动签名。

## Firefox 扩展兼容

- 分别构建和发布 Firefox、Chromium ZIP；Firefox 使用独立的 MV3 后台脚本、扩展 ID 和原生侧边栏。
- 适配 Firefox 的发布页加载、平台脚本注入、本地图片/视频传递及严格网站 CSP，并使用兼容 Firefox 140 的 PDF.js 版本。
- Firefox 不使用 Chromium 标签分组；空闲侧边栏需手动关闭。后台触发账号刷新时会打开扩展标签页。

## 桌面多平台工作台

- 默认桌面入口改为单窗口多平台工作台，复用扩展的动态、视频和文章编辑器、导入功能及平台适配器。
- 平台页面作为窗口内标签运行，支持隔离登录与本地素材传递。普通适配器的自动模式标记「待确认」，不把填充完成当作发布成功；可能已提交的任务不会自动重发。
- 此路径无需模型。原小红书 Agent 试点可通过 `pupu-linux-x64/pupu --agent` 启动，Ollama 和模型仍需单独安装。

## 已验证与限制

- Firefox 140 ESR 与 159 实测侧边栏、PDF 导入，以及模拟平台的文本、图片和 2 MiB 视频填充；Firefox 140 还验证了关闭侧边栏后的后台任务状态。
- Chromium 实测侧边栏和 PDF 导入；自动化单元测试、类型检查、lint 和 Linux 桌面模拟冒烟测试通过。
- Mozilla 自动校验为 0 错误、109 警告；这不代表已通过人工审核或取得签名。
- 桌面多平台与 Firefox 的发布测试使用模拟平台，未对所有真实平台逐一验收，也未执行真实内容发布。登录、验证码和发布结果仍需用户核对。
- Windows/macOS 桌面发行包和手机应用尚未提供。
