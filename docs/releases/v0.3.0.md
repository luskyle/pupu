# pupu v0.3.0

## 下载什么

- **浏览器扩展**：`pupu-v0.3.0.zip`，解压后在 Chrome/Edge 中加载。
- **Linux x64 桌面实验版**：`pupu-desktop-v0.3.0-linux-x64.tar.gz`，解压完整目录后运行 `pupu-linux-x64/pupu`。不需要 Node.js 或浏览器扩展。
- `SHA256SUMS`：两个归档的 SHA-256 校验值。

## 新增桌面 Agent

内容工作台、草稿保存、图片选择、持久隔离的平台登录窗口，以及显式确认任务后的自动上传、标题定位、填写、回读、提交和成功提示检查。
默认模型为本地 Ollama / Qwen3 4B（约 2.5 GB），模型和 Ollama **不包含在安装归档中**。
首次使用先安装 Ollama 并启动服务，通过工作台高级设置下载模型；也可选择 Ollama 可执行文件，由桌面自动启动。

目前只试点小红书图文。模型只读取有限字段标签，不读取正文、图片或登录凭据；正文和图片仍会上传到目标平台。
支持 open/closed shadow DOM。停止不能撤销已提交内容，提交不确定时不会自动重试。

## 修复与校验

- 缺少内容、图片或模型时明确提示，不再静默禁用发布按钮；首次连接失败后可重试。
- 处理编辑器填写后占位提示消失与异步节点替换，仍坚持全文核对和覆盖保护。
- 使用后端节点引用，并仅在页面动作之前限次重新观察，避免重复提交。
- 排除真实小红书页面的屏幕外、近透明入口副本，去重嵌套入口。
- 正常图文/视频准备阶段导航不再误判为登录失败。
- 扩展新增默认关闭的本地 Agent 标题辅助试点；启用该试点后小红书只填写，不自动提交。

## 已验证与限制

- 本机 Linux：真实小红书选择图文、测试图片上传、标题正文填写/延迟回读、发布入口就绪、正常 tab 导航已实测。
- **没有执行真实内容发布**，真实提交及成功回执仍未验收。
- 真实 Electron + Qwen3 本地演示已完成单次提交、回执、权限隔离、覆盖/重复提交保护与完整界面链路。
- CI 校验扩展与桌面类型、单元测试、扩展构建、无模型 Chromium 冒烟和 Linux 桌面归档。
- Windows/macOS、手机 App、多账号选择和全平台桌面迁移尚未交付。
- 图片选择不持久化，重启后需重新添加；登录/验证码仍由用户完成。
