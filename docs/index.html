pupu 🐙

一款多平台内容发布浏览器扩展，一次编辑，轻松将内容同步发布到多个社交平台。

Chrome MV3 扩展 当前版本 {{VERSION}} 最新发布 — MIT 许可

✨ 特性

针对「一次编辑、多平台分发」的场景设计，尽量把重复的复制粘贴收敛成一次操作。

🧭

极简布局

动态 / 视频 / 文章三个发布 Tab 加关于页；发布时通过侧边栏选择平台并确认。

🚀

自动 / 手动发布

底部开关一键切换：自动发布会在填充后直接发布，手动发布只填充内容，由你自己确认。

🖼️

动态

只填内容即可；支持添加图片、导入 PPT / PDF（自动逐页转图片随动态发布）。

内容工具栏提供 # 话题（支持选中文字一键包裹为 #话题#）与 emoji 分类面板（9 类，含颜文字），输入框内话题实时高亮预览。

🎬

视频

上传视频并发布到支持视频的平台。

📝

文章

导入本地 Markdown 并可视化编辑 / 预览渲染，图片随正文一起发布。

📌

平台分组

动态 / 视频 / 文章各自的首选平台单独列出，其余平台归入「其它」，不用在几十个平台里逐个找。

🗂️

侧边栏联动

侧边栏显示当前编辑类型的平台列表，切换 Tab 实时跟随；切到「关于」页时自动关闭侧边栏。

🧠

平台细节适配

例如发布到小红书时自动将 #话题# 转为小红书格式 #话题[话题]#；标题超过 20 字自动跳过标题。

🧑‍🎨

账户头像（12 生肖）

顶栏账户头像按当前月份显示 12 生肖，悬停同时显示生肖与星座；点击头像一键展开侧边栏，可刷新账号 / 清空账号缓存。

🔄

刷新账号

仅点击「刷新账号」才真正抓取各平台账号，打开侧边栏秒开；已登录平台排最前，常用平台其次。

🌗

暗 / 亮主题

默认暗色主题，顶栏一键切换浅色 / 暗色。

💨

轻量弹窗

提示 / 确认 / 配置弹窗均为纯 CSS 轻量弹窗，不依赖重型动画库，弹出跟手流畅。

🚀 安装

下载 .zip 解压后「加载已解压的扩展程序」即可。Edge 与 Chrome 同为 Chromium，共用同一份文件。

  1. 下载并解压

    到 Releases 下载 pupu-v<version>.zip 并解压到任意目录（目录中应能看到 manifest.json）。

  2. 打开扩展管理页并开启开发者模式

    Chrome 输入 chrome://extensions，Edge 输入 edge://extensions，打开右上角「开发者模式」。

  3. 加载已解压的扩展程序

    点击「加载已解压的扩展程序」，选择解压出的目录即可。

为什么没有 .crx？ 自签名 CRX 无法通过拖拽或普通安装流程安装： Chromium 会校验 CRX 内的 proof 是否由 Chrome 应用商店的私钥签名，否则报 CRX_REQUIRED_PROOF_MISSING。这与怎么打包无关，加 manifest 的 key 字段或 update_url 都不解决；唯一可用的 CRX 路径是机器级强制企业策略 （ExtensionInstallAllowlist + ExtensionInstallSources）。
扩展 ID 为 nffpajdealkjpdmjjboneelajanbboig（由签名密钥决定，各版本固定不变）。 安装需开启「开发者模式」，这是不经过应用商店安装的浏览器限制，与扩展本身无关；想彻底摆脱它，唯一途径是上架 Chrome Web Store / Edge 加载项商店。 Safari 暂不支持：Safari 扩展必须由 Xcode 打包成 App 分发，且本扩展依赖的 sidePanel / tabGroups 在 Safari 上并不存在。
也可以直接从源码构建：pnpm install && pnpm build，产物在 build/chrome-mv3-prod/ （本地构建不出 zip / crx，打包由 CI 完成；需要本地打包时用 pnpm build:ci）。

🧱 技术栈

基于 Plasmo 的 Chrome MV3 扩展，React 18 + TypeScript 开发。

界面 React 18、TypeScript、Tailwind CSS、HeroUI、lucide-react

文件导入 pptx-preview（PPT 逐页转图）、pdfjs-dist（PDF 逐页渲染转图）
截图与预览 html-to-image、html2canvas、react-viewer
工程化 pnpm、Biome（检查 / 格式化）、husky + lint-staged、commitlint
